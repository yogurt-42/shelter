# Shelter — 避难所

末世废土地下避难所实时放置策略经营文字游戏。

## 运行

```bash
cd D:/project_s/demo
python -m shelter.main
```

需要 Python 3.12+ 和 Pygame 2.6。

## 操作说明

| 操作 | 效果 |
|------|------|
| 点击标签 [状态]/[建筑]/[人口] | 切换页面 |
| 建筑页拖拽 | 平移地图（上下左右） |
| 左键空地 | 建造房间 |
| 左键废墟 | 查看清理条件 |
| 左键已建房间 | 查看房间信息 |
| 右键已建房间 | 升级/降级/拆除 |
| 人口页 [+]/[−] | 分配/移除工人 |
| 底部输入框 | 输入命令 |
| Esc | 关闭弹窗 |
| Tab | 切换标签 |
| End | 重置日志滚动 |

## 命令

| 命令 | 效果 |
|------|------|
| `/help` | 查看可用命令 |
| `/status` | 查看资源摘要 |
| `//help` | 查看管理员命令 |
| `//clear` | 清空日志 |
| `//hide <标签>` | 隐藏标签页 |
| `//show <标签>` | 显示标签页 |
| `//tabs` | 列出可见标签 |

## 游戏简介

你是一座废弃地下避难所被重新激活的主控 AI。拾荒者触发了入口机关，你从休眠中苏醒。

从破烂不堪的状况开始——第 1 层仅 3 间空地可用，其余全是废墟。你需要：
1. 收集废料，清理废墟，腾出空间
2. 建造发电机、净水房、种植房、仓库
3. 为工种分配人口，让设施运转产出资源
4. 升级设施，逐步向深层挖掘

世界已经崩塌。随着楼层越挖越深，避难所废弃的真相也将浮出水面。
